# Resume Builder

It is an LLM powered app which helps tailor your resume in accordance with the Job Description provided. Using your current resume and the job description this app rephrases your resume using the STAR format and without adding anything what the candidate did not do. 

## Working:
1. Paste the current resume and the job description in the respected textbox and click on Submit.
2. The app sends the resume and the job description to the LLM with the prompt instruction.
3. The tailored resume generated by the LLM is returned and displayed as a Markdown file.

## Environment Variable
Create a .env file in the project root and add your API Key as given: 
```
token=your_api_key_here
model=gpt-4o-mini
```

## To run:
With uv
```
uv sync
uv run main.py
```

With Docker
```
docker build -t resume-builder .
docker run -p 7860:7860 --env-file .env resume-builder
```
